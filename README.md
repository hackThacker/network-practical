## 📌 What is This

**Network Practical** is a curated collection of Cisco Packet Tracer (`.pkt`) lab files covering real-world network architectures — from simple home setups to enterprise-grade campus and banking infrastructures. Each lab includes topology diagrams, configuration documentation, and downloadable `.pkt` files so you can simulate and learn hands-on.

---

## 💡 Why This Repo

| Feature | Details |
|---|---|
| 🖥️ **Ready-to-use labs** | Pre-built `.pkt` files you can open and simulate immediately |
| 📸 **Visual topology diagrams** | Every lab includes a network diagram for quick reference |
| 📄 **Step-by-step documentation** | Clear README guides for each scenario |
| 🏢 **Real-world scenarios** | Covers SOHO, campus, hospital, hotel, banking, and company networks |
| 🔄 **Multiple routing protocols** | Labs for RIP and EIGRP with detailed configuration steps |
| 📞 **VoIP / IP Telephony** | Hands-on IP telephony and VoIP network design |

---

## 🗂️ Topics Covered

- **Simple Networking** — Basic topology and device connectivity
- **SOHO Network Design** — Small Office / Home Office setup
- **Hotel Management Network** — Multi-department hotel infrastructure
- **Campus Network Design** — Multi-building academic network
- **Banking Network Design** — Secure, segmented banking topology
- **Company Network Design** — Corporate LAN/WAN architecture
- **Hospital Network Design** — Critical infrastructure network layout
- **VoIP / IP Telephony** — Voice over IP network configuration
- **DHCP Server & Client** — Dynamic IP addressing with router configuration
- **Routing with RIP** — RIP protocol setup and topology configuration
- **Routing with EIGRP** — EIGRP protocol setup and topology configuration
